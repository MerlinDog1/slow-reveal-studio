# Build status and launch gates

Inspected 28 September 2026 against every numbered section of [README.md](../README.md). [PRODUCT_SPEC.md](PRODUCT_SPEC.md) preserves the full brief. This is a working software prototype, **not a physically validated kit or a live commercial launch**. Example catalogue prices are development fixtures. Generated marketing images are illustrative concepts.

“Implemented” below means code or an artifact exists; it does not imply production service configuration, customer testing or physical approval. “Partial” preserves the remaining scope rather than treating it as completed. External gates need real evidence and an accountable operator. No physical trial, customer result, trade quote or live payment is invented here.

Renderer 1.3 adds a Dots-only fine-detail sampling control and independent template guide colour. Both flow through presets, local/private saves, canonical proofs and production packages. Defaults preserve existing artwork primitives; changes to paid detail/effective guide colour require customer reproof. The eight-photo detail study records digital comparisons only. Bleed, trim/registration marks and spot-white remain dependent on printer specifications; no arbitrary printer defaults were added.

Production and local prototype packages now include two-page A4 draft making guides, exact saved-palette keys and unresolved packing records. Production wrappers bind these to the current immutable revision; historical paid packages stay unchanged. Artwork PDFs use stable metadata and content-derived IDs, with repeatability tested for identical raster inputs. The [eight-page guide examples](KIT_GUIDES.md) passed digital layout review; their instructions and materials still require physical trials.
