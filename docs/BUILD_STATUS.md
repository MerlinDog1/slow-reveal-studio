# Build status and launch gates

Inspected 28 September 2026 against every numbered section of [README.md](../README.md). [PRODUCT_SPEC.md](PRODUCT_SPEC.md) preserves the full brief. This is a working software prototype, **not a physically validated kit or a live commercial launch**. Example catalogue prices are development fixtures. Generated marketing images are illustrative concepts.

“Implemented” below means code or an artifact exists; it does not imply production service configuration, customer testing or physical approval. “Partial” preserves the remaining scope rather than treating it as completed. External gates need real evidence and an accountable operator. No physical trial, customer result, trade quote or live payment is invented here.

Renderer 1.3 adds a Dots-only fine-detail sampling control and independent template guide colour. Both flow through presets, local/private saves, canonical proofs and production packages. Defaults preserve existing artwork primitives; changes to paid detail/effective guide colour require customer reproof. The eight-photo detail study records digital comparisons only. Bleed, trim/registration marks and spot-white remain dependent on printer specifications; no arbitrary printer defaults were added.

Production and local prototype packages include A4 draft making guides (two to five pages, depending on the palette and used markers), exact saved-palette keys and unresolved packing records. Production wrappers bind these to the current immutable revision; historical paid packages stay unchanged. Artwork PDFs use stable metadata and content-derived IDs, with repeatability tested for identical raster inputs. The [eight-page guide examples](KIT_GUIDES.md) passed digital layout review; their instructions and materials still require physical trials.

## Colour Fibonacci Spiral — 28 September 2026

Renderer 1.7.0 adds Monochrome, Eight colours and 16 colours to Fibonacci Spiral's marker-palette selector. Colour designs retain the same golden-angle sites, with fixed-size numbered dots assigned one pen each; quantization error passes to nearby unvisited sites so neighbouring colours mix visually. Blank white is an unmarked candidate. Single-ink size shading remains available. Colour mode has matching SVGs, colour keys, making guides and packing records; sixteen colours use three A4 guide pages. Historical single-ink geometry with an unused palette still exports as single ink. Colour mode requires light canvas and clears inversion when selected. Production availability and physical-trial requirements are unchanged. See [VERIFICATION.md](VERIFICATION.md).

## Fibonacci Spiral replaces Stipple Art — 28 September 2026

Renderer 1.6.0 adds an ordered sunflower dot pattern, following the user's clarification that they wanted Fibonacci spirals rather than a continuous line. Dot centres use golden-angle phyllotaxis in physical units; the photo controls dot area, without random thinning. Sub-minimum highlights stay blank. Easy, Standard and Detailed, ink/tonal controls, magnification, saved settings and matching guides/exports are supported. Stipple is removed from active choices and lab routes; its historical renderer and saved geometry support remain. The new local route is `/lab/fibonacci`. The existing physical-approval gate applies in production. Validation is recorded in [VERIFICATION.md](VERIFICATION.md).

## Finer Colour Blend hero — 28 September 2026

The macaw hero now contains **52,312 dots**, up from 8,834 (5.92 times as many), with a source-matched sixteen-colour palette and finer sampling. The study uses a 1000 x 1250 mm virtual canvas to retain narrow gaps at the denser lattice, within the existing 60,000-mark ceiling; it does not introduce a new catalogue size or change the studio's default marker palette. Its saved geometry, guide, animation sequence and finished SVG are regenerated together. Validation is recorded in [VERIFICATION.md](VERIFICATION.md).

## Staggered colour modes — 28 September 2026

Renderer 1.4.1 changes Colour Blend to a hexagonal dot lattice and offsets alternate TV Weave rows by half a column spacing. TV dashes retain their vertical clearance. Shifted rows have one fewer mark so both edges stay centred inside the safe area; a single column remains straight. Image sampling follows the displaced centres, and colour error passes to actual neighbouring sites, with edge weights redistributed within the artwork. Previews, numbered templates and new packages share the same geometry. Older saved projects follow the existing renderer-review flow; paid snapshots remain immutable. Verification is recorded in [VERIFICATION.md](VERIFICATION.md).

## Preview magnification — 28 September 2026

The main studio preview and enlarged dialog now offer Fit-relative 100–1600% magnification, plus/minus controls and drag/arrow-key panning. SVGs are laid out at the enlarged size so their marks and outlined numbers remain vector detail. Fit resets the view, and changing the photograph or canvas dimensions resets magnification. The enlarged view also has Original, Finished, Template and Compare controls; comparison uses a separate slider so it does not intercept panning. Camera state stays in the preview component and never changes crop settings, saved geometry or export dimensions. Percentages are relative to fitting the available viewport, not calibrated physical display size. Verification is recorded in [VERIFICATION.md](VERIFICATION.md).

## Line Study SVG import compatibility — 28 September 2026

Following a reported diagonal distortion when importing a Line Study template into CorelDRAW, Line Study now serializes each horizontal strip as an independent closed four-corner SVG 1.1 path. Fill, stroke, width, join and opacity are explicit on every strip; zero-radius rectangle primitives and inherited group styling are removed for this mode. The underlying millimetre geometry, mark counts and stored settings are unchanged. This shared serializer covers previews, direct SVG exports and newly generated packages; existing paid packages remain immutable. Geometry and raster comparison regressions cover template and finished output. The user confirmed that the converted 400 x 500 mm replacement displays correctly in CorelDRAW. This verifies that file on their installation; the specific importer failure has not been reproduced in an automated CorelDRAW test.

## Colour Blend and TV Weave labs — 28 September 2026

Renderer 1.4.0 adds two experimental colour activities: Colour Blend uses numbered circular marks; TV Weave uses numbered short vertical dashes. Both distribute eight or sixteen pen colours with deterministic error diffusion in linear RGB, keeping blank white canvas separate. Each mark uses one pen; nearby colours combine visually at viewing distance. The studio, settings/preset validation, saved designs, shared SVG geometry and local/server making guides support both modes. Their keys and packing requirements use the exact saved palette. Neither mode supports inverted dark canvas or Dots-only subject masks.

Five modes are available locally: Dots, Mosaic, Line Study, Colour Blend and TV Weave. Production still defaults to Dots and requires explicit physical approval for alternatives. Old geometry algorithms and paid packages are preserved; the renderer version change invokes the existing review/rebuild path for older saved projects. Source-controlled guide, coupon and social provenance has been refreshed. Number legibility, practical completion time, marker matching and physical optical blending remain unvalidated. White gaps reduce contrast and colour range; this is not calibrated pigment or television emission simulation.

## Revised detail levels — 28 September 2026

The old Easy preset is retired from the built-in choices. Easy now uses the previous Standard settings (4.2 mm spacing), Standard uses the previous Detailed settings (2.8 mm), and Detailed adds a finer 2 mm spacing with 0.5–1.7 mm marks. New studio sessions start on the new Standard. Saved designs retain their explicit settings, and legacy renderer defaults remain unchanged. The renderer still enforces physical bounds, clear gaps and the 60,000-mark ceiling; fine marks and numbered cells still need physical readability trials.

## Mosaic 16- and 32-colour options — 28 September 2026

The Mosaic Lab now offers fixed 16- and 32-marker palettes with an on-screen numbered colour key. Existing 2/4/6/8/16-colour choices retain their exact colours and order. Renderer, private-save and preset validation accept up to thirty-two colours; template numerals, saved settings, local exports and production package colour/packing keys use the same palette. Dots and other modes are unchanged. The existing geometry algorithm/version remains unchanged for previously valid designs.

Palettes above eight colours use separate key and packing pages. Sixteen colours use three A4 pages; thirty-two use four or five, with sixteen keys per page and up to eighteen packing rows per page. Existing smaller-palette guides retain their output. Tests cover all sixteen and thirty-two numbered colours in each Mosaic cell shape, validation boundaries, deterministic exports, unused keys, bounded guide layout, and complete page/hash manifests in local/server packages. Local verification results are recorded in [VERIFICATION.md](VERIFICATION.md).

Marker colour matching, two-digit template legibility and making the full 16- or 32-colour design still require physical trials. Mosaic's production availability and live checkout remain gated.
