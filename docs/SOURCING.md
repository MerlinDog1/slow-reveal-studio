A nib's advertised stroke width is not a verified completed-dot diameter. A stock paint marker's industrial durability is not evidence that it is comfortable or appropriate for an indoor art kit. Request formulation/safety documentation from the selected supplier; do not make lightfastness or archival claims without applicable evidence.

## Sample programme and record schema

Start with one smooth primed cotton, one medium-grain cotton, one rigid canvas board and one roll sample. Pair each with fine/broad black, white and metallic candidates. Expand to 4/6/8 colours only after monochrome passes. Request written quotes for the same five target sizes, 25/100/500-unit batches, delivery destination, VAT basis and lead times. No outreach has been sent.

Record each substrate lot: supplier, SKU, quote date, MOQ, quantity tiers, sizes, gsm, fibre composition, grain, primer, frame depth, tolerance, printer clearance, UV ink adhesion, sharpness, white ink, marker bleed/drag, drying time, shipping resilience, packaging cost, freight, reject allowance and landed cost.

Record each pen lot: SKU, colour, tip shape/diameter, dot consistency, opacity, area per pen, coverage, bleed, drag, smell, dry time, smudge resistance, supplier lightfastness evidence, unit cost, branding MOQ, replacement availability and between-batch colour difference. Record environmental conditions and exact substrate/ink/curing settings with every observation.

Landed unit cost = substrate + print ink/white ink + machine/labour + markers/accessories + packaging + inbound freight/duty + measured waste allowance. Retail prices above are sample-shopping anchors only. Establish margins only after real yield, completion and shipping measurements. Physical pass/fail protocol is in [PRODUCTION.md](PRODUCTION.md).
