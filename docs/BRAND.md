# Slow Reveal Studio brand direction

**Working name; not cleared for launch.** The brand centres on a meaningful image becoming visible through the customer's own repeated marks. It must work for dots, filled cells and traced lines. Product language should describe the physical action and finished object without generic AI claims.

## Voice and hierarchy

Lead with the brief's line: **Made from your photo. Finished by you.** Supporting explanation: upload a favourite image, turn it into a guided canvas, complete it by hand. Primary actions: “Create yours” and “Upload a photo.” Use clear labels for “Original”, “Finished” and “Template”. Refer to unvalidated features as studio experiments in the lab.

Write calmly and directly. Explain suitability in a useful way: “Try a tighter crop so the faces have more room.” Avoid therapeutic/health claims, invented scarcity, invented testimonials, guaranteed likeness or unmeasured completion promises. “Estimated time” is acceptable only with an explanation that it is provisional until physical trials calibrate it.

The interface should favour an uncluttered workbench: large artwork, warm background, restrained controls, readable contrast, clear focus, and subtle transitions that respect reduced-motion preferences. Difficulty is a workload choice, not an ability judgement. Lab sliders can be technical; customer presets should describe the result and making effort.

|---|---|---|
| Ink | `#1E1E1C` | Primary text, finished black art, core buttons |
| Canvas | `#F4EFE6` | Main surface |
| Warm Sand | `#DCCEB6` | Secondary surfaces, quiet separation |
| Soft Gold | `#C6A25A` | Small accents; never sole text contrast |
| Deep Blue | `#445E7C` | Sparing accent / proposed marker treatment |
| Sage | `#7B8B77` | Sparing accent |
| Clay | `#B97A68` | Sparing accent |

Screen colours do not certify marker pigments, metal reflectance or UV ink. Label colour treatments as previews until material testing approves stock. Pair an editorial serif headline with a plain readable UI face; system fonts avoid a new downloaded-font dependency, but production text still needs a deterministic rendering path.

## Evidence and imagery

Keep a visible distinction between rendered examples, generated product concepts and actual photographed kits. Do not present licensed stock subjects as customers. Customer results require explicit permission for the specific marketing use. No automatic gallery publication or training use of uploaded photos. Real production photography should replace concept images through stable asset slots documented in [ASSETS.md](ASSETS.md).
